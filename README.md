# Login & SignUp Using Flutter & MongoDB

This project demonstrates a simple Login, Signup, and Home app built with:    
*Flutter (Frontend UI)  
*Node.js + Express (Backend API)  
*MongoDB (Database)  

# Features  
Signup with Email & Password  
Login with Email & Password  

# Data Validations:  
Email format check  
Password must not be empty  

# Home Page: Displays a static "Welcome" message  

# Tech Stack  
Frontend: Flutter (Dart, HTTP package)  
Backend: Node.js, Express.js  
Database: MongoDB (Mongoose)  
  
# Pages  
Signup Page → Register with email & password  
Login Page → Login with email & password  
Home Page → Displays "Welcome"  

# Validation Rules  
Email must be in valid format (e.g., user@example.com)  
Password cannot be empty
